# Использовать pen.dev-дизайн как UI-контракт

`design/pen-design.pen` является каноническим UI-контрактом для пользовательских
экранов, состояний, визуальных паттернов, reusable-компонентов и визуальных
токенов; `design/new-design.pen` deprecated. Функциональное поведение остается
за specs, доменными документами и API-контрактом. Сохраненная версия `.pen`
является утвержденной, а факты о ней получают напрямую через Pencil tools без
производной статической карты.

Подготовка, реализация и review видимых frontend-изменений следуют
`docs/design/pen-ui-contract.md`. Если нужного design state нет или визуальный
контракт расходится с функциональным требованием, агент останавливается с
`UI Contract Collision`: владелец продукта выбирает обновление дизайна,
изменение требования или явное исключение. Действующие исключения фиксируются
в `docs/design/pen-ui-contract-exceptions.md`.
