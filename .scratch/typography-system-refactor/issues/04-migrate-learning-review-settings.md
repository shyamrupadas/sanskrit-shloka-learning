# 04 — Унифицировать типографику заучивания, повторения, обучения санскриту и настроек

**What to build:** Перевести самостоятельный интерфейсный и санскритский текст сценариев заучивания, повторения, обучения санскриту и настроек на общий типографический контракт. Пользователь должен видеть согласованные заголовки и спокойный foreground, а заголовки и канонический текст шлок должны сохранять Noto Serif при переходе на общую размерную шкалу.

**Blocked by:** 02 — Перевести общие проектные компоненты на Typography

**Status:** awaiting-human-review
Accepted: 2026-08-10

- [x] Самостоятельные заголовки и обычный интерфейсный текст затронутых сценариев используют `Typography` с согласованными variants, weights и tones.
- [x] Заголовки шлок и канонический санскритский текст используют `SanskritTypography`, который не вводит отдельную шкалу поверх `Typography`.
- [x] Заголовок шлоки первого уровня отображается как 20px/1.25/700; остальные санскритские тексты выбраны из согласованных `p1–p4` без произвольных размеров.
- [x] Существующие HTML-уровни, доступные имена, подсказки, результаты повторения и действия пользователя сохранены.
- [x] Интерактивные кнопки, controls и labels продолжают владеть собственной типографикой.
- [x] pen.dev screens отражают новую шкалу и foreground без изменения этапов заучивания, подсказок, результатов повторения или настроек.

- [x] Длинный санскритский текст и отображаемые названия не ломают переносы и mobile layout.
- [x] В затронутом feature-коде не осталось прямых самостоятельных headings/paragraphs или ручной общей типографики вне разрешённых controls.
- [x] Маршруты, параметры, алгоритм повторения, API-контракт, данные и backend не изменены; новые DB migrations не требуются.
