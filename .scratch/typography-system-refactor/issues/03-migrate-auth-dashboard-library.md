# 03 — Унифицировать типографику авторизации, дашборда и общей библиотеки шлок

**What to build:** Перевести самостоятельный текст авторизации, дашборда и общей библиотеки шлок на новый контракт, чтобы заголовки «Библиотека», «Повторите шлоки» и «Выучите шлоки» использовали единый первый визуальный уровень 20px, а остальные тексты этих сценариев получали согласованные размеры, веса и tones без ручной сборки.

**Blocked by:** 02 — Перевести общие проектные компоненты на Typography

**Status:** awaiting-human-review
Accepted: 2026-08-08

- [x] Заголовки «Библиотека», «Повторите шлоки» и «Выучите шлоки» используют `Typography` с вариантом `h1` и размером 20px.
- [x] Существующие HTML-уровни остальных заголовков сохранены; различие между структурным тегом и визуальным вариантом выражено через `as`, а не перенумерацией документа.
- [x] Самостоятельные описания, пустые состояния, сообщения и подписи auth, dashboard и общей библиотеки шлок используют согласованные paragraph variants и semantic tones.
- [x] Текст внутри кнопок, ссылок, полей, вкладок и навигации не оборачивается в `Typography` без самостоятельной текстовой роли.
- [x] Заголовок и канонический текст на странице шлоки используют `SanskritTypography`; заголовок первого уровня уменьшен до согласованных 20px и сохраняет Noto Serif.
- [x] pen.dev screens и связанные product components синхронизированы с новой шкалой и foreground без изменения пользовательских состояний и действий.
- [x] Route-level tests продолжают находить ключевые заголовки по роли и корректному уровню и подтверждают существующее поведение auth, dashboard и library.
- [x] Длинные отображаемые названия и текст шлок не создают overflow-регрессий на поддерживаемых мобильных viewport.
- [x] В затронутом feature-коде не осталось прямых самостоятельных headings/paragraphs или ручных типографических размеров, весов и line-height, кроме разрешённых interactive primitives.
- [x] Маршруты, параметры, API-вызовы, данные и backend не изменены; новые DB migrations не требуются.
- [x] Обязательные frontend-проверки проходят.
