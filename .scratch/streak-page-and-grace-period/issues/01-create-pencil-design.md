# 01 — Создать полноценный дизайн серии дней в Pencil

**What to build:** Полноценно спроектировать и сохранить в Pencil мобильный сценарий серии дней: постоянную кнопку на дашборде и отдельную страницу «Подряд» во всех состояниях. Дизайн должен заменить прежний popup-сценарий и стать каноническим визуальным контрактом для последующей frontend-реализации.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] Выбрана и отрисована новая иконка серии, а ее активное и приглушенное состояния согласованы с существующей дизайн-системой.
- [ ] На всех релевантных состояниях дашборда спроектирована постоянно видимая единая кнопка из иконки и счетчика, включая значение `0`.
- [ ] Кнопка имеет интерактивную область не менее 44×44 px, не получает декоративных hover- или press-эффектов и предусматривает видимый клавиатурный фокус.
- [ ] Создана мобильная страница «Подряд» в существующем shell приложения с back-header и без нижней навигации; глобальный layout и responsive-политика не изменены.
- [ ] Созданы состояния страницы для нулевой серии, ненулевой серии без активности сегодня и серии, продолженной сегодня.
- [ ] Во всех состояниях страницы используется активная иконка, отображаются счетчик, последние пять дней с отметками и утвержденные в спеке тексты.
- [ ] Среди примеров есть нулевая серия с отметками прежней активности в пятидневной истории.
- [ ] Специфические popup-состояния серии удалены из Pencil, при этом общие tooltip/popover-компоненты и токены других функций сохранены.
- [ ] Все новые и измененные Pencil-узлы сохранены, визуально проверены и перечислены стабильными pen.dev references для реализации и человеческого принятия.
