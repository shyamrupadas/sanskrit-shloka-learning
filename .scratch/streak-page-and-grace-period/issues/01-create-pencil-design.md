# 01 — Создать полноценный дизайн серии дней в Pencil

**What to build:** Полноценно спроектировать и сохранить в Pencil мобильный сценарий серии дней: постоянную кнопку на дашборде и отдельную страницу «Подряд» во всех состояниях. Дизайн должен заменить прежний popup-сценарий и стать каноническим визуальным контрактом для последующей frontend-реализации.

**Blocked by:** None — can start immediately
