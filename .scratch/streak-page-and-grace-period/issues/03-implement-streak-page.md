# 03 — Реализовать кнопку и страницу «Подряд»

**What to build:** Реализовать целостный frontend-сценарий серии дней: пользователь всегда видит кнопку на дашборде, открывает по ней защищенную страницу «Подряд» и получает состояние, счетчик и пятидневную историю из ответа backend. Все состояния должны соответствовать принятому Pencil-дизайну и корректно обновляться после значимой активности.

**Blocked by:** 01 — Создать полноценный дизайн серии дней в Pencil; 02 — Расширить API серии льготным периодом и пятидневной историей

**Status:** ready-for-agent

- [ ] Кнопка серии постоянно видна на дашборде, включая нового пользователя, завершенную серию и значение `0`.
- [ ] Иконка и число образуют одну семантическую кнопку с понятным доступным именем, целью не менее 44×44 px и видимым клавиатурным фокусом.
- [ ] У кнопки нет декоративных фона, рамки, тени, hover-анимации или press-анимации.
- [ ] Иконка кнопки приглушена до значимой активности сегодня и активна после нее; при значении `0` она приглушена.
- [ ] Нажатие на иконку или число открывает защищенный маршрут `/streak` в существующем shell приложения.
- [ ] Страница показывает заголовок «Подряд», принятую активную иконку во всех состояниях и счетчик с правильной русской формой слова «день».
- [ ] Пять локальных календарных дней выводятся от самого раннего к сегодняшнему с однобуквенными русскими обозначениями и фактическими отметками активности.
- [ ] При значении `0` выводится текст «Повтори или выучи хотя бы одну шлоку, чтобы начать свою серию!», даже если в истории сохранились прежние отметки.
- [ ] Для ненулевой серии без активности сегодня выводится текст «Повтори или выучи хотя бы одну шлоку, чтобы продолжить свою серию!».
- [ ] После значимой активности сегодня выводится текст «Ты в ударе! Возвращайся завтра, чтобы продолжить серию.».
- [ ] Стрелка «Назад» явно ведет на дашборд, включая прямое открытие `/streak`; обычное системное действие «Назад» после перехода с дашборда также возвращает туда.
- [ ] На странице «Подряд» отсутствует нижняя навигация, но глобальный layout и responsive-политика приложения не изменены.
- [ ] После завершенного повторения или перевода шлоки в состояние «повторяю» существующая инвалидация данных обновляет кнопку и открытую страницу без ручной перезагрузки.
- [ ] App/router integration-тесты с реальной маршрутизацией, сессией, React Query и точным mock API покрывают переход, возврат, прямое открытие, все три состояния, историю, доступность и обновление после активности.
- [ ] Специфический tooltip или popup серии не реализован; общие tooltip/popover primitives других функций не изменены.
- [ ] Реализация визуально сверена с принятыми Pencil-узлами в одинаковом мобильном viewport, а использованные pen.dev references перечислены в итоговом отчете тикета.

## UI Contract Collision

- На момент публикации тикета новые узлы страницы и иконки еще отсутствуют в сохраненном визуальном контракте.
- Блокирующий тикет 01 обязан устранить это расхождение и быть принят человеком; начинать видимую frontend-реализацию до этого нельзя.
