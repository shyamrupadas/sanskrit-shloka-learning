# Реализация тикета 02 — создание и редактирование советов

> Уточнение от 2026-09-19: описание `VITE_ADMIN_LEARNING_ENABLED` ниже сохраняет историю первоначальной реализации и не является действующей инструкцией. По [решению владельца](decisions/06-single-admin-without-feature-flags.md) переключатель удаляется; админка единая и доступна по роли без специальных переменных. Существующие флаги повторения не меняются. Актуальный результат исправления — в конце `implementation-03.md`.


Дата: 2026-09-19. База: `ddc2ed82bf3d52156f4970cfd53c78ee5e01443c`.

Реализованы административные POST `/api/admin/learning/tips` и PATCH `/api/admin/learning/tips/{tipId}`, отдельные формы, список и навигация новой админки. Заголовок и текст обрезаются по краям и проверяются сервером независимо от клиента; пределы 120/2000 считаются в Unicode code points, как `char_length` PostgreSQL. Внутренние переносы и обычный текст сохраняются. Создание совета и русской версии выполняется одной транзакцией. Блокировка `learning_tips` сериализует добавления, в том числе в пустой список; позиция берётся после блокировки. Обновление обоих полей — один UPDATE. Репозиторий использует внутренние `LearningTipContent`/`LearningTipRecord`, HTTP-граница — generated contract.

Форма сохраняет ввод после ошибки, предупреждает об уходе через ссылку/отмену/native Back и beforeunload. После успешной записи возвращает в список с сообщением о публикации. Редактор получает свежий материал при входе; автоматические обновления при фокусе и reconnect отключены, чтобы не уничтожать ввод. Завершившееся сохранение уже закрытой формы не перенаправляет пользователя обратно.

## Граница поставки

**Новая админка выключена по умолчанию.** `VITE_ADMIN_LEARNING_ENABLED=true` предназначен сейчас только для локального preview. Без него `/admin` сохраняет прежний каталог, а новые маршруты возвращают администратора в него. Неадминистратор не получает доступа независимо от флага. Нижняя пользовательская навигация в админке отсутствует.

Единый список содержит места действий порядка и удаления; эти кнопки пока disabled. Это подготовка общего экрана, а не отдельный выпускаемый вариант списка. Их поведение и окончательная проверка активных/краевых состояний принадлежат тикету 03. **Не включать флаг при выпуске до завершения 03 и smoke развёрнутых API.** Во время реализации 03 блокировку порядка согласовать с транзакцией добавления.

Предшествующие implementation tickets «Советы из БД» и дизайн 01 имеют `Accepted: 2026-09-19`; совместимая модель и общий GET присутствуют в рабочей базе. Их внешнее развёртывание этим отчётом не подтверждается.
