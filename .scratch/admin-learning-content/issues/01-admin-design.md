# 01 — Подготовить UI-контракт админки и управления советами

**What to build:** Подготовить принятый и сохранённый дизайн единой админки с каталогом и управлением советами по выбранному варианту отдельных страниц.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] В «Еще» административный вход заменён на «Админка»; главная предлагает «Каталог шлок» и «Обучение». Каталог сохраняет свои действия и формы.
- [ ] «Обучение» сразу показывает список советов с заголовком, кратким текстом, порядком и удалением. Промежуточного меню «Советы» и заглушек курсов нет.
- [ ] Подготовлены два этапа поставки списка: создание/редактирование без ещё не реализованных операций и полный список с порядком и удалением. Первый этап не показывает неработающие кнопки.
- [ ] Создание и редактирование показаны отдельными страницами на мобильной и широкой ширине; нет постоянного меню разделов и редактора рядом со списком.
- [ ] Формы включают обязательные поля со счётчиками 120/2000, «Сохранить», «Отмена», ошибки без потери ввода и обратную связь об успешной публикации.
- [ ] Показаны загрузка, ошибка с повтором, пустой список с добавлением первого совета, ошибки перестановки/удаления и недоступные направления на краях.
- [ ] Подготовлены подтверждение необратимого удаления с названием совета и подтверждение ухода из изменённой формы с возможностью остаться.
- [ ] Возвраты соответствуют вложенности: форма → список → главная админки → «Еще»; «В приложение» ведёт в «Еще». Пользовательская нижняя навигация в админке отсутствует.
- [ ] Проверены мобильная и широкая композиции, длинные тексты, clipping/overlap; переиспользована дизайн-система, новые элементы обоснованы.
- [ ] Live-изменения выполнены через MCP в каноническом документе; effective properties изменённых ref проверены до screenshots.
- [ ] Владелец принял и сохранил дизайн; агент проверил сохранённые узлы через read-only inspection, включая resolveInstances. До этого задача не считается завершённой.
- [ ] Актуальные pen.dev references, состояния и evidence переданы тикетам реализации. Продуктовый код не менялся.

## Проверки

Design review с layout evidence, screenshots, effective properties и read-only подтверждением после human save. Дизайн можно готовить параллельно первой спецификации; готовность её API для этой задачи не требуется.

## UI Contract Collision

- Требование: Главная админки, вход из «Еще», каталог с обновлёнными возвратами, список советов, формы, подтверждения и состояния операций.
- pen.dev reference: актуальные references для полного объёма ещё не подготовлены; исторические сведения из карты не являются новой проверкой. В рамках декомпозиции .pen не читался и не менялся.
- Расхождение: согласованный UX пока не подтверждён полным актуальным сохранённым UI-контрактом для этой задачи.
- Варианты решения:
  1. Обновить дизайн и получить human save с последующей проверкой сохранённых узлов.
  2. Изменить требование отдельным решением владельца.
  3. Разрешить design exception отдельным явным решением владельца с записью в реестр.
- Рекомендация агента: выбран вариант 1. Эта задача закрывает коллизию через подготовку дизайна; агент не сохраняет canvas за владельца. Выполнять pen-ui-contract; исключений пока нет.
