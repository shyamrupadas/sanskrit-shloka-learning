# 01 — Подготовить UI-контракт админки и управления советами

**What to build:** Подготовить принятый и сохранённый дизайн единой админки с каталогом и управлением советами по выбранному варианту отдельных страниц.

**Blocked by:** None — can start immediately

**Status:** awaiting-human-review
Accepted: 2026-09-19

- [x] В «Еще» административный вход заменён на «Админка»; главная предлагает «Каталог шлок» и «Обучение». Каталог сохраняет свои действия и формы.
- [x] «Обучение» сразу показывает список советов с заголовком, кратким текстом, порядком и удалением. Промежуточного меню «Советы» и заглушек курсов нет.
- [x] Подготовлен единый список с созданием, редактированием, рабочей сортировкой и удалением. Вариант без сортировки исключён владельцем. Каждый экран расположен на верхнем уровне canvas и имеет индивидуальное штатное название Pen; объединяющих контейнеров нет.
- [x] Создание и редактирование показаны отдельными страницами на мобильной ширине; нет постоянного меню разделов и редактора рядом со списком.
- [x] Формы включают обязательные поля со счётчиками 120/2000, «Сохранить», «Отмена», ошибки без потери ввода и обратную связь об успешной публикации.
- [x] Показаны загрузка, ошибка с повтором, пустой список с добавлением первого совета, ошибки перестановки/удаления и недоступные направления на краях.
- [x] Подготовлены подтверждение необратимого удаления с названием совета и подтверждение ухода из изменённой формы с возможностью остаться.
- [x] Возвраты соответствуют вложенности: форма → список → главная админки → «Еще». Возврат оформлен ссылкой по образцу страницы шлоки; отдельного действия «В приложение» нет. Пользовательская нижняя навигация в админке отсутствует.
- [x] Проверены мобильная композиция, длинные тексты, clipping/overlap; переиспользована дизайн-система, новые элементы обоснованы.
- [x] Live-изменения выполнены через MCP в каноническом документе; effective properties изменённых ref проверены до screenshots.
- [x] Владелец принял и сохранил дизайн; агент проверил сохранённые узлы через read-only inspection, включая resolveInstances. До этого задача не считается завершённой.
- [x] Актуальные pen.dev references, состояния и результаты проверок переданы тикетам реализации. Продуктовый код не менялся.

## Результат

Владелец принял дизайн; агент проверил screenshots, layout и сохранённые effective properties 35 корней, включая 27 экранов админки и 9 экземпляров Modal. Различия вычисляемых текстовых bounds между CLI и Desktop — 1–3 px, суммарная высота формы отличается на 6 px; сохранённые свойства совпадают, clipping/overlap нет. Design exceptions нет. Standards и Spec review — без замечаний. `pnpm test` и `pnpm typecheck` прошли (4/4 Turbo tasks из кеша в каждой проверке). Продуктовый код не менялся.
