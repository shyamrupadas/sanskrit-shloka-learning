# 03 — Безопасное завершение заучивания

**What to build:** Пользователь один раз подтверждает решение `Выучил`, видит честное состояние операции и может безопасно восстановиться после определённой или неоднозначной ошибки без неявного повторения команды перевода шлоки в повторение.

**Blocked by:** 01 — Origin-aware оболочка попытки

**Status:** awaiting-human-review
Accepted: 2026-09-05

- [x] `Выучил` без дополнительного подтверждения отправляет одну существующую команду перехода `learning → reviewing` с IANA-таймзоной; pending-state показывает `Сохраняем…` и отключает `Отмена`, `Совет`, `Помощник` и повторный `Выучил`, не перехватывая системный Back.
- [x] Подтверждённая ошибка, при которой переход гарантированно не состоялся, показывает понятное сообщение и разрешает только явное `Попробовать снова`; повторный POST невозможен до этого действия.
- [x] Потеря соединения, timeout, нечитаемый ответ или иной неоднозначный исход после POST автоматически запускает только GET актуальной шлоки: `reviewing` ведёт к успеху, `learning` разрешает явный повтор, другой статус проходит через безопасный guard.
- [x] Ошибка проверочного GET показывает `Результат пока неясен`; любое число действий `Проверить статус` выполняет только GET, а новый POST возможен лишь после подтверждения `learning` и явного `Попробовать снова`.
- [x] App-level integration tests различают method и path, падают на неожиданный запрос и доказывают число и порядок POST/GET для pending, подтверждённой ошибки и всех исходов неоднозначного результата.
- [x] Существующие backend-инварианты перехода, значимой активности, списка оставшихся шлок и идемпотентной повторной команды остаются зелёными; новые backend tests добавляются только при фактическом изменении этого поведения.
- [x] Lint, web и API typecheck, целевые web integration tests и затронутые API tests проходят.
