# 04 — Устойчивый успех и осознанное продолжение

**What to build:** После подтверждённого успеха пользователь видит точный устойчивый результат, по умолчанию завершает цепочку в исходном контексте либо осознанно начинает следующую или самостоятельно выбранную шлоку без переноса временного состояния прежней попытки.

**Blocked by:** 02 — Советы внутри активной попытки; 03 — Безопасное завершение заучивания

**Status:** awaiting-human-review
Accepted: 2026-09-06

- [x] Success-state остаётся на месте до действия пользователя, показывает отображаемое название и сообщение о переводе шлоки в повторение, а главным действием делает `Закончить`.
- [x] `Закончить` заменяет success-route проверенным исходным `returnTo`; библиотека, дашборд и серия дней после завершения читают актуальное состояние через существующие query boundaries.
- [x] Первая шлока из актуального стабильно упорядоченного списка «буду учить» предлагается как `Учить следующую`; действие отсутствует при пустом списке, а самостоятельный выбор остаётся доступным для веток many, one и none.
- [x] `Учить следующую` заменяет success-route новой попыткой и переносит первоначальный проверенный `returnTo`; самостоятельный выбор заменяет route библиотекой и завершает прежнюю цепочку.
- [x] Новая попытка сбрасывает серию советов, ошибки, неоднозначный результат и success-state предыдущей шлоки; Back/Forward не возвращает пользователя прямо в завершённую попытку.
- [x] App-level integration tests проверяют устойчивый успех, invalidation данных, ветки many/one/none, перенос `returnTo`, replace-семантику и сброс attempt-scoped состояния по наблюдаемым URL, истории и запросам.
- [x] Lint, web typecheck и целевые web unit/integration tests проходят.
