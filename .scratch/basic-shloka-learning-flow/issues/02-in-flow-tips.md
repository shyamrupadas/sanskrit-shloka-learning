# 02 — Советы внутри активной попытки

**What to build:** Пользователь получает один совет поверх неизменённой попытки, последовательно просматривает неповторяющуюся серию и при необходимости открывает существующую страницу всех советов, не теряя контекст и не изменяя статус шлоки.

**Blocked by:** 01 — Origin-aware оболочка попытки

**Status:** awaiting-human-review
Accepted: 2026-09-05

- [x] `Совет` открывает modal bottom sheet с одним советом, позицией в серии до её исчерпания, явным закрытием, действиями `Другой совет` и `Все советы`; после исчерпания серии позиция не показывается, а тексты берутся из существующего источника страницы советов без второго каталога.
- [x] `Другой совет` показывает только ещё не просмотренный совет текущей попытки, после третьего совета становится недоступным и получает подпись `Других советов нет`.
- [x] Закрытие и повторное открытие сохраняют текущий совет и просмотренную серию, переход на `Все советы` и нативный Back восстанавливают ту же незавершённую попытку, а новая попытка начинает новую серию.
- [x] Dialog имеет доступное имя, блокирует фоновые действия, удерживает фокус, закрывается по Escape и возвращает фокус на `Совет`; закрытие не отправляет mutation-команд и не меняет данные попытки.
- [x] App-level integration tests проверяют перебор и исчерпание серии, закрытие/reopen, переход на все советы и Back, сброс новой попытки, inert background и полный focus lifecycle по наблюдаемым ролям и действиям.
- [x] Lint, web typecheck и целевые web unit/integration tests проходят.
