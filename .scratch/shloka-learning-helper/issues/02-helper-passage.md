# 02 — Линейный проход Помощника внутри попытки

**What to build:** Пользователь из активной попытки проходит спокойный пошаговый цикл по четырём падам и их объединениям, в любой момент возвращается к полному тексту и только на базовом экране решает, переводить ли шлоку в повторение.

**Blocked by:** 01 — Детальное API-представление шлоки с падами

**Status:** ready-for-agent

- [ ] Рабочее действие `Помощник` открывает режим только из актуальной активной попытки со статусом «буду учить», передаёт уже проверенную шлоку и возвращается в ту же route/page shell без нового `returnTo`.
- [ ] Проход строит только из `padas` семь фрагментов в порядке `1`, `2`, `1+2`, `3`, `4`, `3+4`, `1+2+3+4`; клиент не использует эвристическое разбиение полного текста.
- [ ] Каждый фрагмент линейно проходит фазы `прочитать → воспроизвести → свериться`: канонический текст показывается, затем скрывается и снова показывается, а нижнее действие соответствует текущей фазе; финальная сверка всей шлоки предлагает `Вернуться к шлоке`.
- [ ] Header всегда содержит `К шлоке` и `Помощник`, meta-блок показывает название и позицию из семи, сегментированный progress различает завершённые, текущий и будущие фрагменты, а фаза выражена доступным текстом и семантикой, не только цветом.
- [ ] `К шлоке` из любой фазы и финальный возврат не отправляют mutation-команд, не меняют статус и не создают значимую активность; повторный вход, reload или новая попытка начинают с первой пады.
- [ ] `DATA_INTEGRITY_ERROR` и другие ошибки детального GET используют стандартное состояние ошибки базовой shell: активная попытка и `Помощник` недоступны, retry повторяет GET и открывает режим только после корректного ответа.
- [ ] App-level integration tests проходят все три фазы семи фрагментов, проверяют порядок, видимый текст, действия и прогресс, досрочный возврат из каждой фазы, повторный вход с начала и отсутствие `complete-learning` или других mutation-запросов.
- [ ] Lint, web и API typecheck, целевые web unit/integration tests и затронутые API/contract tests проходят.
