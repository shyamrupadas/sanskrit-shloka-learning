# 01 — Подготовить UI-контракт серверных советов

**What to build:** Подготовить принятый и сохранённый дизайн страницы «Советы» и диалога во время заучивания, по которому можно реализовать получение материалов с сервера.

**Blocked by:** None — can start immediately

**Status:** awaiting-human-review
Accepted: 2026-09-19

- [x] Сохранены существующие представления содержимого: список раскрываемых советов, диалог, последовательный переход, исчерпание серии, закрытие и «Все советы».
- [x] Для обоих потребителей подготовлены загрузка, ошибка с «Повторить» и успешный пустой ответ «Советов пока нет». Диалог можно закрыть при ошибке и пустом ответе.
- [x] Показаны мобильная и широкая композиции, длинные заголовки и тексты не вызывают clipping или overlap.
- [x] Дизайн переиспользует существующие компоненты и токены; новые элементы дизайн-системы обоснованы фактической недостаточностью существующих.
- [x] Live-изменения выполняются через MCP в каноническом документе. Для изменённых ref проверены effective descendant properties, получены layout evidence и screenshots.
- [x] Владелец выполнил review и сохранение; агент подтвердил сохранённые узлы через read-only inspection, включая resolveInstances для ref. До этого задача не считается завершённой.
- [x] В отчёте записаны актуальные pen.dev references и покрытые состояния; ссылки переданы задаче реализации. Исторические references из карты не используются как кеш свойств.
- [x] Функциональные решения спецификации не изменены. По явному дополнению владельца добавлен общий компонент адаптивной модалки; серверное подключение остаётся задачей 02.
