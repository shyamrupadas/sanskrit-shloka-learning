# 01 — Подготовить UI-контракт серверных советов

**What to build:** Подготовить принятый и сохранённый дизайн страницы «Советы» и диалога во время заучивания, по которому можно реализовать получение материалов с сервера.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] Сохранены существующие представления содержимого: список раскрываемых советов, диалог, последовательный переход, исчерпание серии, закрытие и «Все советы».
- [ ] Для обоих потребителей подготовлены загрузка, ошибка с «Повторить» и успешный пустой ответ «Советов пока нет». Диалог можно закрыть при ошибке и пустом ответе.
- [ ] Показаны мобильная и широкая композиции, длинные заголовки и тексты не вызывают clipping или overlap.
- [ ] Дизайн переиспользует существующие компоненты и токены; новые элементы дизайн-системы обоснованы фактической недостаточностью существующих.
- [ ] Live-изменения выполняются через MCP в каноническом документе. Для изменённых ref проверены effective descendant properties, получены layout evidence и screenshots.
- [ ] Владелец выполнил review и сохранение; агент подтвердил сохранённые узлы через read-only inspection, включая resolveInstances для ref. До этого задача не считается завершённой.
- [ ] В отчёте записаны актуальные pen.dev references и покрытые состояния; ссылки переданы задаче реализации. Исторические references из карты не используются как кеш свойств.
- [ ] Продуктовый код и функциональные решения спецификации не изменены.

## Parent

[Советы из БД](../spec.md).

## Проверки

Проверка — layout, screenshots и effective properties live-узлов, затем сохранённых узлов после human save. Продуктовые тесты не требуются: меняется только дизайн.

## UI Contract Collision

- Требование: Страница «Советы» и диалог с загрузкой, ошибкой, пустым ответом и исчерпанием серии.
- pen.dev reference: актуальные references для полного объёма ещё не подготовлены; исторические сведения из карты не являются новой проверкой. В рамках декомпозиции .pen не читался и не менялся.
- Расхождение: согласованный UX пока не подтверждён полным актуальным сохранённым UI-контрактом для этой задачи.
- Варианты решения:
  1. Обновить дизайн и получить human save с последующей проверкой сохранённых узлов.
  2. Изменить требование отдельным решением владельца.
  3. Разрешить design exception отдельным явным решением владельца с записью в реестр.
- Рекомендация агента: выбран вариант 1. Эта задача закрывает коллизию через подготовку дизайна; агент не сохраняет canvas за владельца. Выполнять pen-ui-contract; исключений пока нет.
