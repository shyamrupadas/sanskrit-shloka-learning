# 02 — Перевести страницу и серию советов на данные из БД

**What to build:** Пользователь читает серверные советы на отдельной странице и во время заучивания; начатая серия сохраняет список и позицию при возврате и перезагрузке, а новые входы получают актуальное содержимое.

**Blocked by:** 01 — Подготовить UI-контракт серверных советов

**Status:** awaiting-human-review

- [x] Совет хранится отдельно от языковых версий, имеет стабильный id и общий порядок; пара «совет — локаль» уникальна, осиротевших версий нет. Заголовок и текст обязательны с пределами 120/2000 символов.
- [x] Авторизованный пользователь без административной роли получает полный упорядоченный список id/title/text на русском; локаль не передаётся и настройки учётной записи не расширяются. Пустой список — успешный ответ.
- [x] Три исходных совета однократно перенесены без изменения текстов и порядка. Повторные развёртывания не затирают дальнейшие правки и не восстанавливают удаления.
- [x] Страница «Советы» читает свежий список при каждом входе и перезагрузке, сохраняет раскрытие/сворачивание и не меняет содержимое фоновым обновлением во время чтения.
- [x] Первое открытие диалога запрашивает список; первый успешный ответ фиксирует состав, порядок и тексты до конца попытки. Повторные открытия используют сохранённый список.
- [x] Советы идут последовательно без повторов; после последнего переход недоступен и виден конец серии. Закрытие диалога позицию не меняет.
- [x] Переход «Все советы» → назад и перезагрузка сохраняют незавершённую попытку, список и текущую позицию. Чтение отдельной страницы не продвигает серию.
- [x] Изменение, добавление, удаление и перестановка на сервере не меняют сохранённую серию. Отдельная страница может уже показывать новые тексты; новая попытка получает свежий список при первом открытии диалога.
- [x] Завершение или отмена попытки очищают только её серию. Поздний ответ предыдущей попытки не заменяет состояние новой.
- [x] Ошибка загрузки видна отдельно, допускает повтор и не фиксирует пустой список. Успешный пустой список фиксируется до конца попытки и показывает «Советов пока нет». Диалог можно закрыть и продолжить заучивание.
- [x] При старом формате с одним индексом однократно перезапускается только серия советов; попытка и пользовательский прогресс сохраняются. Повтор прежнего совета при переходе допустим.
- [x] После переключения обоих потребителей встроенный массив не используется как источник или fallback; серверного хранения серии, синхронизации устройств и фоновых подписок нет.
- [x] TypeSpec, generated artifacts и реализация согласованы; проверки API чтения, миграции, contract, UI и browser-сохранения проходят.
- [ ] До выпуска frontend применены миграции и проверены фактически развёрнутый API и начальные данные. Backend выпускается аддитивно, пока старый клиент продолжает работать.
- [ ] Оба потребителя, сохранение серии и переход старого формата включены одним выпуском frontend после готовности API и дизайна. Работоспособность каталога и заучивания сохранена.
- [x] Визуальная проверка приложения выполнена по актуальному сохранённому контракту; в отчёте перечислены references, evidence, автор review и миграции, которые необходимо применить.
