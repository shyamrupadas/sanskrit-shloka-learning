# 01 — Исследовать методы заучивания коротких текстов

Type: research
Status: resolved
Blocked by: None - can start immediately

## Question

Какие подтверждённые исследованиями методы помогают взрослому пользователю за 1–4 минуты продвинуться в заучивании короткого четырёхчастного текста, и какие из них подходят для минимального опционального «Помощника» без автоматической проверки ответа?

## Answer

Для минимального опционального «Помощника» принято ядро `прочитать → скрыть → воспроизвести → показать оригинал и свериться`: retrieval practice и корректирующая обратная связь имеют наиболее сильную поддержку, а распознавание речи для мнемонической пользы не требуется. Последовательность `1 → 2 → 1+2 → 3 → 4 → 3+4 → все четыре` подходит как простая UX-гипотеза для прототипа, но не считается доказанно оптимальной; шаги остаются мягкими, без автоматической оценки и сохранения промежуточного прогресса. Spacing обеспечивается будущими сессиями повторения, а кнопка «Выучил» трактуется как пользовательское решение перейти к ним, не как измеренная проверка точности.

Подробные доказательства, границы применимости и UX-инференсы: [исследование методов заучивания](../research/memorization-methods.md).
