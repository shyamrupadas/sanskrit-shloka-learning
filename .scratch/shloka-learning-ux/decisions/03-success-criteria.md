# 03 — Определить критерии успеха нового флоу

Type: grilling
Status: resolved
Blocked by: None - can start immediately

## Question

По каким наблюдаемым качественным критериям владелец поймёт, что новый флоу стал удобнее черновика, не вводя на этом этапе продуктовую аналитику и историю попыток?

## Answer

Успех прототипа оценивается по понятности и управляемости UX, а не по фактическому качеству запоминания, точности воспроизведения или произношению. Строгий таймер не применяется: целевые 1–4 минуты остаются ориентиром короткой попытки, при этом быстрый путь должен быть доступен сразу, без обязательных промежуточных экранов.

Для принятия прототипа владелец подтверждает соблюдение продуктовых правил и понятность обоих самостоятельных путей: быстрого пути с прямым действием «Выучил» и опционального «Помощника» с возвратом в основной сценарий. Способ проверки, состав участников и границы доказательности определены в [«Определить способ и участников проверки прототипа»](13-prototype-validation.md).

Прототип требует исправления, если хотя бы в одном сценарии пользователь не понимает, что «Выучил» переводит шлоку в повторение; не может отменить незавершённую попытку без изменения статуса и с возвратом в исходный контекст; теряет попытку при просмотре совета; либо попадает к следующей шлоке без отдельного согласия. Эти нарушения считаются блокирующими независимо от общей положительной реакции.

Текущая реализация используется как источник известных проблем, а не как эталон для прямого сравнения.
