# 10 — Собрать цельный текстовый UX-прототип

Type: prototype
Status: resolved
Blocked by: 04 — Спроектировать базовую попытку заучивания; 06 — Спроектировать минимальный «Помощник» по падам; 07 — Спроектировать советы без выхода из заучивания; 08 — Спроектировать завершение и осознанное продолжение; 09 — Определить навигацию с возвратом в исходный контекст

## Question

Как все согласованные решения складываются в единый текстовый wireflow со всеми пользовательскими текстами, действиями, переходами и граничными состояниями базового флоу и «Помощника»?

## Prototype

- [Цельный текстовый wireflow заучивания](../prototypes/integrated-text-wireflow/README.md): одноразовый интерактивный HTML с девятью маршрутами проверки и видимым state inspector.

## pen.dev references

- `Заучивание — шлока` (`QPXXW`), saved state inspected 2026-09-02: mobile frame 390×844, Noto Serif для названия и текста шлоки; старые действия `Повторить`/`Добавить` и bottom navigation не принимаются как функциональный контракт.
- `Заучивание — подтверждение` (`IQcqK`), saved state inspected 2026-09-02: mobile frame 390×844, отдельный success-state, success icon и существующие primary/secondary button patterns; старые действия не принимаются как функциональный контракт.
- Состояния «Помощника», in-flow dialog совета, origin-aware выхода и неоднозначного сохранения в saved design отсутствуют. Прототип описывает их для будущей визуальной проверки и не меняет канонический `.pen`.

## Answer

Принят единый текстовый wireflow из девяти проверочных маршрутов. Базовая попытка сразу показывает полный текст и независимые действия `Выучил`, `Помощник`, `Совет` и `Отмена`; отдельного выбора режима или подтверждения результата нет. Во время запроса `Выучил` все конфликтующие экранные действия недоступны, а неоднозначный сетевой результат сначала разрешается перечитыванием актуального статуса без повторной mutation-команды.

«Помощник» следует согласованному циклу из семи фрагментов и трёх фаз `прочитать → воспроизвести по памяти → свериться`. Он не оценивает ответ, не сохраняет прогресс и после последнего фрагмента возвращает к полной шлоке, не меняя её статус. Совет показывается поверх неизменённой попытки, сохраняет неповторяющуюся серию в пределах попытки и позволяет отдельно перейти на существующую страницу «Советы» с возвратом по истории.

После подтверждённого успеха устойчивый экран сообщает переход конкретной шлоки в повторение. Главным действием остаётся `Закончить`; новая попытка начинается только после явного `Учить следующую`, а самостоятельный выбор шлоки завершает прежнюю цепочку. `Отмена`, `Закончить`, fallback прямой ссылки и status guard следуют принятой модели проверенного `returnTo` и замены записи истории.

Владелец принял интерактивный прототип 2026-09-02 после проверки в отдельном Chrome. Он становится функциональным текстовым источником для будущего mobile-first визуального прототипа; отсутствующие saved pen.dev states остаются предметом следующего визуального решения, а не неявным design exception.
