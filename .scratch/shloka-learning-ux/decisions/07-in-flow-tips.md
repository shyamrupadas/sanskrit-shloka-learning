# 07 — Спроектировать советы без выхода из заучивания

Type: prototype
Status: resolved
Blocked by: 02 — Исследовать мобильные паттерны сфокусированного заучивания; 04 — Спроектировать базовую попытку заучивания

## Question

Как на мобильном экране показывать один совет, действие «Другой совет» и ссылку «Все советы», чтобы помощь была доступной, не перекрывала критичные действия и не выбрасывала пользователя из попытки?

## Prototype

- [Три варианта советов внутри попытки](../prototypes/in-flow-tips/README.md): интерактивный mobile-first HTML с вариантами `A`, `B`, `C`, неповторяющейся серией советов и отдельным состоянием её исчерпания.

## pen.dev references

- `Заучивание — шлока` (`QPXXW`), saved state inspected 2026-08-31: frame 390×844, Noto Serif для названия и текста шлоки; старые действия и bottom navigation не принимаются как функциональный контракт.
- `Product / Tip Accordion Item / Collapsed` (`epjBK`) и `Product / Tip Accordion Item / Expanded` (`rgPsh`), saved state inspected 2026-08-31: подтверждают визуальные свойства существующей страницы советов, но не являются in-flow dialog pattern.
- In-flow tip dialog: not found in saved design; варианты прототипа исследуют будущий state и не изменяют канонический `.pen`.

## Answer

Принят вариант A «Один совет». Нажатие «Совет» открывает компактный modal bottom sheet, семантически представленный как доступный dialog. Фон попытки становится неактивным: пользователь не может случайно нажать «Выучил», «Помощник» или «Отмена», пока читает совет. В шапке листа остаются заголовок «Совет» и явное закрытие; закрытие или `Escape` возвращает пользователя к неизменённой попытке и восстанавливает фокус на вызвавшем действие «Совет».

В листе показан один из трёх существующих моковых советов. «Другой совет» — единственное основное действие: оно последовательно показывает ещё не просмотренный в текущей попытке совет без повторов. Закрытие и повторное открытие листа сохраняют текущий совет и множество уже просмотренных советов до конца попытки; новая попытка начинает новую серию.

После третьего совета действие «Другой совет» становится недоступным с подписью «Других советов нет», а status-сообщение объясняет, что все советы текущей сессии показаны. Ссылка «Все советы» остаётся доступной и ведёт на существующую страницу «Советы» без её редизайна. Возврат по истории должен восстановить незавершённую попытку; точный общий механизм origin-aware навигации остаётся в решении «Определить навигацию с возвратом в исходный контекст».

Канонический pen.dev пока не содержит принятого in-flow dialog state. Прототип фиксирует UX-решение для будущего текстового и визуального контракта, но сам `.pen` и продуктовый код в рамках этого решения не меняются.
