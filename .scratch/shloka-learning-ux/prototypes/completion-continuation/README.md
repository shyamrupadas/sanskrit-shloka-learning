# Прототип завершения и осознанного продолжения

Три варианта устойчивого success-state после «Выучил», переключаемые через
`?variant=A|B|C`. Прототип проверяет иерархию «Закончить», «Учить следующую» и
«Выбрать следующую шлоку»; это одноразовый planning-артефакт, а не продуктовый
код.

Запуск из корня репозитория:

```bash
python3 -m http.server 4174 --directory .scratch/shloka-learning-ux/prototypes/completion-continuation
```

Открыть: <http://localhost:4174/?variant=A>

Нижняя тёмная панель принадлежит только прототипу. Стрелки меняют вариант,
селектор задаёт количество оставшихся шлок в статусе «буду учить», а блок
`state` показывает полное состояние после каждого действия.
