# Прототип базовой попытки заучивания

Три варианта существующей страницы заучивания, переключаемые через
`?variant=A|B|C`. Это одноразовый planning-артефакт, а не продуктовый код.

Запуск из корня репозитория:

```bash
python3 -m http.server 4173 --directory .scratch/shloka-learning-ux/prototypes/base-learning-attempt
```

Открыть: <http://localhost:4173/?variant=A>

Нижняя тёмная панель принадлежит только прототипу: стрелки меняют вариант,
селектор воспроизводит ожидание и ошибки, а блок `state` показывает полное
состояние после каждого действия.
