«Помощник» по падам

Вопрос прототипа: достаточно ли понятна и мягка модель, где пользователь читает фрагмент, скрывает его, воспроизводит по памяти и сверяется — без автоматической оценки и сохранения промежуточного прогресса?

Внешний вид не является предложением для pen.dev. Здесь проверяются только состояния, тексты действий и разрешённые переходы.

Полное состояние

Обновляется после каждого действия; доменные факты показаны словами, а не JSON.

Свободная проверка

Все действия доступны всегда. Невозможный переход должен быть отклонён с объяснением.
