# Логический прототип «Помощника»

Одноразовый planning-артефакт для проверки переходов минимального «Помощника»
по падам. Это не утверждённый визуальный дизайн и не продуктовый код.

Откройте [`index.html`](index.html) двойным кликом. Сервер и зависимости не
нужны.

Что проверить:

1. Пройдите сценарий «Весь путь» и оцените, понятен ли повторяющийся цикл без
   отдельного объяснения.
2. В сценарии «Повтор и пропуск» проверьте, достаточно ли мягкими ощущаются
   действия без оценки «правильно / неправильно».
3. В сценарии «Выход и возврат» убедитесь, что новый запуск ожидаемо начинается
   с первой пады, а статус шлоки нигде не меняется.
4. В свободном режиме попробуйте действия в неожиданном порядке: прототип
   должен отклонить невозможный переход и объяснить причину в панели состояния.

Сохранённый pen.dev-контракт, просмотренный перед прототипированием:

- `Заучивание — шлока` (`QPXXW`) — полный текст и действия исходной попытки;
- `Заучивание — подтверждение` (`IQcqK`) — старое состояние после успеха.

Состояний «Помощника» в сохранённом контракте нет. Их визуальный дизайн остаётся
за последующим ticket карты.
