Одноразовый logic prototype

Цельный wireflow заучивания

Вопрос: складываются ли принятые решения в один предсказуемый путь, где пользователь понимает последствия каждого выхода, а быстрый путь и «Помощник» не мешают друг другу?

Внешний вид намеренно схематичен. Проверяются пользовательские тексты, состояния и переходы; канонический pen.dev этим прототипом не меняется.

Маршруты проверки

Каждый маршрут начинает сценарий с известного состояния; дальше используйте действия на экране телефона.

Результат запроса «Выучил»

Сеть может ответить однозначно, оставить прежний статус или не позволить определить результат.

Оставшиеся шлоки

Меняет только содержимое устойчивого success-state.

Полное состояние

Инспектор показывает доменные последствия, которые интерфейс не должен скрывать.
