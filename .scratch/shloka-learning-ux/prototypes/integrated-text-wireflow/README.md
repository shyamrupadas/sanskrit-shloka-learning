# Цельный текстовый wireflow заучивания

Одноразовый logic prototype, который объединяет принятые решения базовой
попытки, «Помощника», советов, завершения и origin-aware навигации. Это не
продуктовый код и не предложение визуального дизайна для pen.dev.

Запуск из корня репозитория:

```bash
python3 -m http.server 4173 --directory .scratch/shloka-learning-ux/prototypes/integrated-text-wireflow
```

Открыть: <http://localhost:4173/>

Прототип можно проходить свободно через экран телефона или открыть один из
проверочных сценариев справа. После каждого действия полный state показан в
инспекторе.

## Что проверить с владельцем

1. Быстрый путь доступен сразу, а «Выучил» однозначно означает переход в
   повторение без подтверждения.
2. «Помощник» воспринимается как опциональный мягкий проход, его завершение не
   меняет статус и возвращает к полной шлоке.
3. Совет не разрывает попытку; «Другой совет» не повторяет показанное, а
   «Все советы» — осознанный выход на существующую страницу.
4. «Отмена» и «Закончить» возвращают в исходный контекст, а новая попытка не
   начинается без отдельного действия.
5. Тексты состояний загрузки, неоднозначного сохранения и status guard не
   обещают результат, которого система ещё не подтвердила.

  «Повторить»/«Добавить» и bottom navigation не переносятся.
- `Заучивание — подтверждение` (`IQcqK`), saved state inspected 2026-09-02:
  frame 390×844, отдельный success-state, success icon и существующие
  primary/secondary button patterns. Старые действия не переносятся.
- Состояния «Помощника», in-flow dialog совета, origin-aware выхода и
  неоднозначного сохранения в сохранённом дизайне отсутствуют. Этот wireflow
  описывает функциональные состояния для будущего визуального прототипа и не
  меняет канонический `.pen`.
