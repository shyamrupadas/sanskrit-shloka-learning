# Визуальный прототип флоу заучивания

Одноразовый mobile-first UI prototype для решения
«Проверить визуальный прототип флоу заучивания». Три структурно разные
композиции работают поверх одного и того же согласованного сценария и
переключаются через `?variant=A`, `?variant=B` и `?variant=C`.

Запуск из корня репозитория:

```bash
python3 -m http.server 4174 --directory .scratch/shloka-learning-ux/prototypes/visual-flow
```

Открыть: <http://localhost:4174/?variant=A>

Варианты:

- **A — Спокойный фокус:** нейтральная верхняя панель, текст как главный объект,
  помощь вторична, `Выучил` закреплён внизу.
- **B — Учебное поле:** шлока собрана в отдельную рабочую область, помощь
  заметнее и объясняется до действия, результат остаётся отдельным решением.
- **C — Текст прежде всего:** редакционная иерархия без карточки вокруг шлоки,
  `Выучил` следует сразу за текстом, помощь уходит в компактный нижний блок.

Кнопки A/B/C в блоке «Варианты компоновки», стрелки в плавающей панели и клавиши
`←`/`→` меняют вариант с сохранением текущего состояния. Справа доступны
сценарии для экспертной проверки; на узком экране лаборатория находится под
прототипом. Блок «Текущее состояние» показывает все существенные последствия
действий.

## Что проверить с владельцем

1. Какой вариант лучше удерживает шлоку в центре внимания, не пряча `Выучил`.
2. Достаточно ли заметны `Помощник` и `Совет`, оставаясь опциональными.
3. Понятны ли три фазы «Помощника» и его несохраняемый прогресс.
4. Читается ли совет как временный слой над той же попыткой.
5. Достаточно ли явно success-state отделяет `Закончить` от нового выбора.
