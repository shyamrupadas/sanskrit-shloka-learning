Одноразовый UI prototype: три композиции одного флоу. Плавающая тёмная панель не является частью продукта.

Варианты компоновки

Переключение сохраняет текущее состояние флоу.

Сценарии проверки

Сценарий меняет только стартовое состояние. Дальше используйте действия внутри телефона.

Ответ после «Выучил»

Прототип не вызывает API: выберите результат запроса.

Текущее состояние

Полный релевантный state после каждого действия и переключения варианта.
