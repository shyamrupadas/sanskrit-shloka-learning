# Прототип советов внутри попытки

Три варианта compact modal bottom sheet на принятом базовом экране заучивания,
переключаемые через `?variant=A|B|C`. Это одноразовый planning-артефакт, а не
продуктовый код и не обновление канонического pen.dev-дизайна.

Запуск из корня репозитория:

```bash
python3 -m http.server 4173 --directory .scratch/shloka-learning-ux/prototypes/in-flow-tips
```

Открыть: <http://localhost:4173/?variant=A>

Нижняя тёмная панель принадлежит только прототипу. Стрелки меняют вариант,
селектор открывает заданное состояние серии советов, а блок `state` показывает
полное состояние после каждого действия.

## Что сравнить

- `A — Один совет`: спокойная текстовая иерархия, одно основное действие.
- `B — Колода`: явный счётчик и визуально отделённый совет.
- `C — Компактный лист`: минимальная высота и равный доступ к трём исходам.

Во всех вариантах фон попытки неактивен, `Escape` и «Закрыть» возвращают фокус
на кнопку «Совет», «Другой совет» не повторяет уже показанные советы до
исчерпания текущей сессии, а «Все советы» явно моделирует переход на
существующую страницу.
