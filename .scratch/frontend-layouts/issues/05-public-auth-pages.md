## Проверка

Сохранённые `J9sKf` и `Wklvv` перечитаны через read-only pen.dev CLI: область контента 390 px, карточка 350 px, горизонтальные поля 20 px. Агент сопоставил их со скриншотами приложения через Playwright MCP при 390×844, включая ошибку регистрации; проверены композиция, размеры, отступы, типографика, цвета и состояния. Исключений из UI-контракта нет.

При 390×360 и ошибке регистрации внутренняя область прокручивается на 181 px, а документ — на 0 px; нижняя ссылка достижима. E2E-проверка повторяет это для входа и регистрации до и после появления ошибки. `pnpm lint`, web typecheck, unit-тесты (233), сборка и e2e-тесты (19) прошли.
