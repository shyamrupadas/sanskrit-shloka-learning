# 05 — Вход и регистрация

**What to build:** Пользователь видит страницы входа и регистрации с согласованными размерами и отступами общей композиции; формы полностью доступны при прокрутке без лишних закреплённых областей.

**Blocked by:** 01 — Общий лейаут и заучивание

**Status:** ready-for-agent

- [ ] Вход и регистрация во всех существующих состояниях используют общие правила высоты и основной прокрутки без обрезания формы или непредусмотренной внешней прокрутки.
- [ ] Состав экранов, действия форм и поведение авторизации сохранены; отсутствие шапки или нижней панели не оставляет пустых областей.
- [ ] Вход и регистрация используют общую композицию страницы без дополнительного публичного или защитного визуального лейаута; существующие `beforeLoad`-переходы для уже вошедшего пользователя сохранены.
- [ ] Проверки существующих сценариев входа и регистрации проходят.
