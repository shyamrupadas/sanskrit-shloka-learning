# 02 — Повторение

**What to build:** Пользователь проходит повторение с теми же правилами прокрутки и закрепления областей, что и заучивание, при этом каждая существующая стадия показывает только свои шапку и действия.

- [x] Длинное содержимое и все действия доступны; переходы между состояниями не смещают закреплённые элементы.
- [x] Возврат и остальные действия повторения сохраняют существующее поведение; соответствующие интеграционные и браузерные проверки проходят.

## pen.dev references

Сохранённые экраны: `Повторение — текст скрыт` (`M6fBeF`), `Повторение — загрузка` (`rGP2I`), `Повторение — ошибка загрузки` (`mtk6Y`), `Повторение — завершение` (`LwsXw`). Перед реализацией перечитать соответствующие состояния по `pen-ui-contract`.

## Проверка реализации

Все четыре состояния используют `ScreenLayout`: шапка закреплена, содержимое занимает оставшуюся высоту и прокручивается внутри экрана, а нижние действия присутствуют только при повторении и завершении. Заголовок ошибки согласован с сохранённым экраном. Интеграционные тесты подтвердили действия и возврат; браузерный тест на `390×480` подтвердил загрузку, ошибку, длинный текст, завершение и отсутствие отдельной прокрутки документа. `pnpm lint`, web typecheck, build и `pnpm test` прошли.

Агент сопоставил сохранённые Pen-узлы `M6fBeF`, `rGP2I`, `mtk6Y`, `LwsXw` со скриншотами основного, ошибочного и завершённого состояний приложения в Playwright MCP на `390×844`; загрузка дополнительно проверена браузерным тестом. Проверены состав областей, размеры, отступы, типографика, цвета и состояния. Исключений из UI-контракта нет. Владелец поручил закрыть тикет 2026-09-27.
