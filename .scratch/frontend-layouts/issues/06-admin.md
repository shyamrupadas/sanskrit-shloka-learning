# 06 — Админка

**What to build:** Администратор открывает разделы админки и редактирует длинные формы в той же системе высоты, шапки и прокрутки; последнее поле и действия остаются доступными.

**Blocked by:** 01 — Общий лейаут и заучивание; 04 — Страница шлоки, серия дней и оболочка авторизованной зоны

**Status:** awaiting-human-review
Accepted: 2026-09-28

- [x] Все существующие экраны и состояния админки используют общую композицию; длинные каталоги и формы прокручиваются до конца без внешней прокрутки или перекрытия действий.
- [x] Заголовки, возвраты и защита несохранённых изменений работают как прежде; отдельная прокрутка модального диалога остаётся внутри него.
- [x] `AdminLayout` удалён как визуальная оболочка. Админские маршруты находятся во вложенной группе без собственного UI: родительская группа проверяет вход, админская группа проверяет актуальную подтверждённую сервером роль через `beforeLoad`. Страницы задают свою композицию явно.
- [x] Браузерная проверка длинной формы и существующие проверки админских сценариев проходят.

Проверить прямой вход и перезагрузку админского маршрута для гостя, обычного пользователя и администратора, в том числе при устаревшей сохранённой роли. Редиректы для действительных состояний сессии сохранить; API продолжает независимо проверять права на каждом запросе.
